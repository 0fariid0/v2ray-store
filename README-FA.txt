به‌روزرسانی روشن/خاموش کردن کانفیگ برای مدیر و نماینده

نصب:
از فایل‌های فعلی بکاپ بگیرید و فایل‌های این بسته را با حفظ مسیرها در پوشهٔ ربات جایگزین کنید.
ابتدا settings/configPower.php و settings/receiptSimilarity.php، سپس config.php و bot.php را منتقل کنید.
فایل configPower.php جدید است. فایل receiptSimilarity.php همان وابستگی به‌روزرسانی رسید ۹۰روزه است و برای کامل بودن بسته همراه آن قرار دارد.
فایل baseInfo.php، توکن، اطلاعات اتصال و پوشهٔ settings را به‌صورت کلی حذف یا جایگزین نکنید؛ فقط فایل‌های نام‌برده منتقل شوند. SQL دستی لازم نیست؛ مجوز اختصاصی در جدول setting فعلی ذخیره می‌شود.

مسیر فعال‌کردن مجوز نماینده:
مدیریت ربات ← گروه مربوطه ← مدیریت نمایندگان ← فهرست نمایندگان ← نمایندهٔ موردنظر ← «قیمت و تحویل»
گزینهٔ «روشن/خاموش کردن کانفیگ» را از «غیرمجاز» به «مجاز» تغییر دهید.
این مجوز برای همهٔ نمایندگان، در نبود تنظیم اختصاصی، خاموش است. برای هر نماینده جداگانه ذخیره می‌شود و تخفیف‌ها یا تنظیمات دیگر او را تغییر نمی‌دهد.

رفتار:
- مدیر اصلی و ادمین‌های ربات به این دکمه دسترسی دارند.
- نماینده فقط با مجوز اختصاصی و برای کانفیگی که در ربات متعلق به خودش است می‌تواند اقدام کند.
- کاربر عادی دکمه را نمی‌بیند؛ ارسال دستی callback هم اجازه نمی‌دهد.
- در صفحهٔ جزئیات کانفیگ، برای کانفیگ روشن «غیرفعال کردن» و برای کانفیگ خاموش «فعال کردن» نمایش داده می‌شود.
- با قطع مجوز، دکمه‌های قبلی نماینده هم اجازهٔ اجرا ندارند. حذف نمایندگی مجوز را خاموش می‌کند. کانفیگ‌هایی که قبلاً خاموش شده‌اند خودبه‌خود روشن نمی‌شوند.
- وضعیت از پنل خوانده می‌شود. اگر خواندن معتبر نباشد، دکمهٔ تغییر نشان داده نمی‌شود. پس از اجرای درخواست نیز وضعیت نهایی دوباره بررسی می‌شود.
- کلیک دوباره روی همان فرمان، وضعیت را معکوس نمی‌کند؛ مثلاً فرمان غیرفعال‌سازی مجدد، کانفیگ را روشن نخواهد کرد.
- دکمهٔ قدیمی مدیر در اولین کلیک فقط صفحه را به‌روز می‌کند تا دکمهٔ امن جدید نمایش داده شود.
- مسیر برگشت و صفحهٔ نماینده حفظ می‌شود؛ صفحهٔ مدیریت کاربران برای نماینده نمایش داده نمی‌شود.

پنل:
برای 3x-ui جدید دارای API مرکزی clients، درخواست enable/disable فقط برای همان ایمیل کلاینت ارسال می‌شود و روی همهٔ اتصال‌های آن کلاینت اعمال می‌شود. اگر پنل این API را نداشته باشد یا خطا بدهد، موفقیت اعلام نمی‌شود.
مسیرهای قدیمی sanaei/alireza و Marzban نیز پشتیبانی شده‌اند. در حالت اینباند اختصاصی، وجود چند کلاینت مانع اقدام می‌شود تا کلاینت‌های دیگر خاموش نشوند.
فعال‌کردن کانفیگ، تمدید یا شارژ حجم نیست؛ زمان و حجم تمام‌شده باید از مسیر معمول تمدید شوند. سفارش حذف/لغوشده با این دکمه احیا نمی‌شود.

اعتبارسنجی:
۵۹ بررسی محلی برای مجوزها، مالکیت، نقش مدیر، عدم دسترسی کاربران عادی، مجوز پیش‌فرض خاموش، لغو دسترسی، درخواست قدیمی، فرمان تکراری، خطاهای پنل، مسیر برگشت، منوی واقعی تنظیمات و بدنهٔ درخواست پنل پاس شده است.
تست‌های قبلی منو و رسید نیز بررسی شدند؛ کد بررسی رسید نسبت به بستهٔ قبلی تغییر نکرده است.
تست زنده روی پنل و سرور شما انجام نشده است. پس از نصب، روی یک کانفیگ آزمایشی نماینده، خاموش/روشن کردن و سپس لغو مجوز آن نماینده را بررسی کنید.
